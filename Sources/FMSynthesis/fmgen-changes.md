# fmgen からの改変内容

本ディレクトリの `FMSynthesizer.swift` は cisc 氏の fmgen (FM Sound Generator)
を Swift へ移植したものです。原典の著作権表示および利用条件は同ディレクトリの
`fmgen-readme.txt` (原文のまま無改変で同梱) を参照してください。

利用条件 3「改変したソースコードを配布する際は改変内容を明示すること」に基づき、
原典からの改変内容を以下に記します。

移植元: [BubiC-8801MA](https://github.com/bubio/BubiC-8801MA) 同梱の
`src/vm/fmgen/` — cisc 1998, 2003 版。

## 1. 言語移植

C++ から Swift への移植です。アルゴリズム、テーブル、固定小数点表現、
`param_changed_` / `Prepare()` による遅延パラメータ再計算といった構造は
原典を踏襲しています。

移植したのは **FM 合成コアのみ** (`FMSynthesizer.swift`) です。SSG、ADPCM、
リズム、タイマー、レジスタインターフェースは `YM2608.swift` に別途実装しており、
fmgen の `psg.cpp` / `opna.cpp` の移植ではありません (ADPCM の一部処理のみ
fmgen の挙動を参照しています。該当箇所はコメントで明示)。

## 2. 挙動の変更

| 変更 | 内容 |
|---|---|
| PG アンダーフローのラップ (PR #99) | F-Number 0 と負の DT1 の組み合わせで、位相増分を乗算前に 18bit (実機 OPN の 17bit 加算器相当) でラップさせる。原典は負の値のまま保持するため無音になる |
| SSG-EG ログテーブルのアンダーフロー修正 (#34) | 負のインデックスでテーブル範囲外を参照する問題を修正 |
| ADPCM のエイリアシング修正 (#14) | ADPCM をチップ内部レートではなく音声出力レートでデコードするよう変更 |
| ADPCM RAM リミットのラップ修正 (#17) | リミットアドレス到達時のアドレスラップ処理を修正 |

## 3. 追加した機能

原典にない機能として以下を追加しています。

- **セーブステート対応** — `FMSynthesizerSerialize.swift` / `YM2608Serialize.swift`
  による内部状態のシリアライズ/デシリアライズ
- **CD ミックス出力段** — 1 極ローパスフィルタと Schroeder リバーブによる
  出力段 (`AudioPostProcessor.swift`)。既定は無効
- **イマーシブ/空間音声出力** — チャンネル別ステレオバッファの生成
- **デバッグ用チャンネルミュート** — FM/SSG/ADPCM/リズムの個別ミュート
  (`DebugOutputMask`)
